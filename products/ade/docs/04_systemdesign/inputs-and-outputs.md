## 1. Input Payloads

### 1.1 ade_v1 Flow

**Required**:
```json
{
  "dataset": "branded_cards_transactions"
}
```

**Optional**:
```json
{
  "prompt": "Analyze Q4 spending trends",
  "intent": "...",
  "question": "...",
  "instructions": "...",
  "upload_id": "run_upload_id",
  "files": [{"name": "sample.csv", "file_type": "csv"}]
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `dataset` | string | Yes | Dataset name (CSV file name) |
| `prompt` | string | No | Analyst question (primary input) |
| `intent` | string | No | Alternate intent input |
| `question` | string | No | Alternate question input |
| `instructions` | string | No | Alternate instructions input |
| `upload_id` | string | No | Upload tracking identifier (passed through to core) |
| `files` | list | No | Uploaded file descriptors (passed through to core) |

## 3. User Inputs (HITL)

### 3.1 viz_preferences

**Form ID**: `viz_preferences`

```yaml
title: "Visualization preferences"
mode: "choice_input"
required:
  - "chart_type"
  - "metric_focus"
defaults:
  chart_type: "bar"
  metric_focus: "mean"  # or "anomalies" for visualization flow
  include_hypothesis_checks: true
  notes: ""
```

| Field | Type | Options | Description |
|-------|------|---------|-------------|
| `chart_type` | string | bar, line, area, scatter | Chart visualization type |
| `metric_focus` | string | mean, sum, median, growth_rate, anomalies | Metric aggregation focus |
| `include_hypothesis_checks` | boolean | true/false | Run hypothesis tests |
| `notes` | string | free text | Optional user notes |

## 5. Output Artifacts

### 5.1 Primary Outputs

| Output | Format | Description |
|--------|--------|-------------|
| `business_report.html` | HTML | Primary stakeholder report |
| `decision_packet.html` | HTML | Supporting decision summary |

Output payload fields (non-exhaustive):
- `stop_reason` in `DecisionPacket` and `BusinessReport`
- `version_metadata` in `DecisionPacket` and `BusinessReport`

**Evidence**:
- `products/ade/schemas/decision_packet.py` (`DecisionPacket.stop_reason`, `DecisionPacket.version_metadata`)
- `products/ade/schemas/business_report.py` (`BusinessReport.stop_reason`, `BusinessReport.version_metadata`)
- `products/ade/tools/render_decision_packet_html.py` (advisory label in HTML)
- `products/ade/tools/render_business_report_html.py` (advisory label in HTML)

### 5.2 Output Quality Gates

Quality checks are enforced during business report assembly:
- Executive summary and findings must be present.
- Findings must include evidence references.
- Recommendations must be specific (minimum word count).
- Visuals must include data payloads.

**Validation Gating (TS-BRD-VAL-001..003)**:
- All outputs validated against Pydantic schemas before rendering
- `ValidationGate` class blocks rendering when validation fails
- Clear validation errors with field paths via `format_pydantic_errors()`

**Evidence**:
- `products/ade/tools/assemble_business_report.py` (`_validate_report_quality`, `_validate_visuals`)
- `products/ade/utils/validation.py` (`ValidationGate`, `validate_output_schema`, `format_pydantic_errors`)

### 5.3 Optional Outputs (via export_pdf)

| Output | Format | Description |
|--------|--------|-------------|
| `ade.pdf` | PDF | Exported PDF report |
| `ade.html` | HTML | Exported HTML |
| `ade_stub.json` | JSON | Stub data for testing |

### 5.4 Output Location

Output files are persisted by the core runtime under:
```
observability/ade/<run_id>/output/
├── business_report.html
├── decision_packet.html
└── response.json
```

**Evidence**:
- `products/ade/tests/integration/test_ade_v1.py` (`observability/ade/<run_id>/output/response.json`)

## 6. Artifact Flow

### 6.1 Step-to-Step Data Flow

```
Payload
  │
  ├─▶ data_reader ──▶ columns, rows, series, data, x_field, y_field
  ├─▶ context_pack_builder ──▶ dataset_profile, coverage, missingness
  │
  ├─▶ viz_preferences ──▶ chart_type, metric_focus, include_hypothesis_checks
  │
  ├─▶ compute_business_metrics ──▶ totals, movers, anomalies, evidence_items
  │
  ├─▶ sufficiency_evaluator ──▶ confidence_level, downgrade_reasons
  ├─▶ critic_evaluator ──▶ evidence_gaps, revised_confidence, blocking_required
  │
  ├─▶ detect_anomalies ──▶ anomalies, evidence_items
  │
  ├─▶ hypothesis_test_* ──▶ status, reasoning, evidence_items
  │
  ├─▶ build_chart_spec ──▶ chart_spec
  │
  ├─▶ assemble_decision_packet ──▶ decision_packet
  │
  ├─▶ assemble_business_report ──▶ report
  │
  └─▶ render_*_html ──▶ HTML files
```

**Evidence**:
- `products/ade/flows/ade_v1.yaml` (step `context_pack`)
- `products/ade/tools/context_pack_builder.py` (`ContextPackBuilderTool`)
- `products/ade/agents/critic_evaluator.py` (`CritiqueOutput`)

### 6.2 Template Reference Syntax

```yaml
# Tool output
"{{artifacts.tool.<tool_name>.output.<field>}}"

# User input
"{{artifacts.user_input.<form_id>.values.<field>}}"

# Agent output
"{{artifacts.agent.<agent_name>.output.<field>}}"

# Payload
"{{payload.<field>}}"
```
